# CaliperPlus – Car Detailing Website

CaliperPlus is a modern and responsive car detailing business website designed to showcase vehicle detailing services, improve customer engagement, and provide an easy enquiry system.

The project combines a professional UI with practical backend integration, making it suitable for both real-world business use and academic presentation.

---

## Features

- Responsive design for desktop, tablet, and mobile
- Hero section with brand introduction
- About / Who We Are section
- Service packages and add-on services
- Why Choose Us section
- Customer testimonials and reviews
- Contact and enquiry form
- Backend integration for storing customer enquiries
- Firebase + MySQL database connectivity
- Hosted using GitHub Pages

## Project Objective

The main objective of CaliperPlus is to create a professional digital platform for a car detailing business where customers can:

- Explore detailing services
- View service packages
- Submit enquiries easily
- Access business information from any device

The project also demonstrates the practical implementation of SDLC, responsive web design, and frontend-backend integration.
